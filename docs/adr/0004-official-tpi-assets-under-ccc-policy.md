# 使用 TPI 官方素材并遵守社区创作内容政策

魔典上的座位用官方角色图标比自绘或纯文字更易辨认，也贴近血染钟楼本身。The Pandemonium Institute 在 `botc-release` 仓库与 release.botc.app 公开了供社区工具使用的素材（角色图标、剧本 logo、社区创作内容标志），使用条件是遵守其 [Community Created Content Policy](https://bloodontheclocktower.com/pages/community-created-content-policy)。我们只使用资源页列出的素材，下载后自行托管，不引用官方 URL；官网自用的背景图与字体不在授权清单内，不使用。

## Considered Options

- **自绘图标或用文字代替角色图标**：没有授权约束，但辨识度低、离游戏本身远，被否决。
- **直接引用 release.botc.app 的 URL**：省去托管，但官方声明这些 URL 可能变化，访问稳定性也不可控，被否决。

## Consequences

- 界面必须常驻显示社区创作内容（CCC）标志，表明本项目不是官方产品；删除它等于违反政策。
- 项目不得商业化，也不得与官方 App 竞争；政策可被 TPI 随时修改，该约束由维护者自行跟进。
- 官方素材更新时需要手动重新下载。
