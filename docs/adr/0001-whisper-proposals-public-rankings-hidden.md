# 私聊提议公开，私聊排序不公开

谁在私聊分配的哪一轮提议了什么成员组合（包括选择不私聊）是可用于推理的有效信息，因此私聊提议的受众定为公开、提交后立即对全体座位可见；其推理摘要的受众仍随决策只给提议者本人。私聊排序暴露的是谁拒绝了谁，暂不公开，受众保持仅观战者。

## Considered Options

- 私聊提议保持仅观战者可见（原设计）：选手只知道包含自己的候选私聊房间，丢掉了“谁想找谁”这条推理线索。
- 私聊房间成立后才公开提议：需要额外的延后事件，且同一轮的私聊排序无法利用它，收益不抵复杂度。

## Consequences

- 选手做私聊排序时已能看到本轮全部私聊提议，包括不涉及自己的。
- 受众按事件类型决定，旧事件日志不迁移：回放旧对局时公开视角也会看到私聊提议，恢复中的对局在之后的决策里也会带上它们。
